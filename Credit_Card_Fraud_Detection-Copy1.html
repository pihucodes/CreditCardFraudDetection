from sklearn.metrics import (
    precision_score,
    recall_score,
    f1_score,
    accuracy_score,
    average_precision_score
)
import pandas as pd

models = {
    "Class Weighting": (model_lr, pred_lr),
    "Undersampling": (model_under, pred_under),
    "SMOTE": (model_smote, pred_smote)
}

results = []

for name, (model, predictions) in models.items():
    probabilities = model.predict_proba(X_test)[:, 1]

    results.append({
        "Method": name,
        "Accuracy": accuracy_score(y_test, predictions),
        "Fraud Precision": precision_score(
            y_test, predictions, zero_division=0
        ),
        "Fraud Recall": recall_score(
            y_test, predictions, zero_division=0
        ),
        "Fraud F1-score": f1_score(
            y_test, predictions, zero_division=0
        ),
        "Average Precision": average_precision_score(
            y_test, probabilities
        )
    })

comparison = pd.DataFrame(results).set_index("Method")

display(comparison.round(4))

Conclusion¶

This project investigates credit card fraud detection using Statistical Machine Learning techniques. Exploratory Data Analysis revealed a severe class imbalance, with fraudulent transactions representing only a very small proportion of the dataset.

The dataset was divided into training and testing sets using stratified sampling. Logistic Regression was implemented using three approaches: class weighting, random undersampling, and SMOTE.

The models achieved high recall for the fraudulent class, detecting approximately 92% of fraud cases in the test set. However, their precision was low, indicating that many legitimate transactions were incorrectly flagged as fraudulent.

Among the three experiments, SMOTE achieved the highest displayed fraud F1-score. Nevertheless, further evaluation is necessary before deciding which approach is most suitable. This project demonstrates why accuracy alone is insufficient for imbalanced classification and why precision, recall, F1-score, and Average Precision are important evaluation metrics.

Future work could investigate alternative classification algorithms, decision thresholds, and additional methods for reducing false positives while maintaining high fraud detection recall.
